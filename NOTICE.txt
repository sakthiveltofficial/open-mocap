--------------------------------------------------------------------------------
Changes from BlendCap 1.0.5 (summary; see the git history for details)
--------------------------------------------------------------------------------

  - Renamed the add-on and its identifiers (blendcap -> openmocap) and
    removed the original branding assets, store links and donation links.
  - Added the Fast capture engine: save_mp_data.py and
    pipeline/mp_skeleton.py (Google MediaPipe pose + hand landmarks,
    solved onto the same skeleton layout the SAM 3D Body pipeline uses).
  - Added the Fast / Pro engine switch to the Capture panel and made the
    BVH pipeline read the skeleton embedded in a capture (torch is no
    longer needed to generate a BVH).
  - Moved the torch-free preview helpers from save_mhr_data.py to
    pipeline/body_preview.py so both engines share them.
  - Added installer/ (install.py, install.sh, install.ps1, install.bat):
    a uv-based installer for the Fast, Pro or both engines that downloads
    models from their official sources.
  - Small fixes: template export without a capture, preset file names,
    the MoGe offline path variable.
  - Rewrote README, NOTICE, CONTRIBUTING and parts of docs/.
